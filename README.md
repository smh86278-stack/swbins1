# 디스패치

메일로 일을 맡기는 **메신저형 보내기 화면**입니다. 아이폰 Safari에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다(설치 없음).

- 서버가 없습니다. 보내기를 누르면 메일 앱이 제목·본문이 채워진 채 열리고, 보내기만 누르면 됩니다.
- 받는 쪽은 PC의 메일 게이트웨이입니다. 답은 메일로 오고, 메일 안의 단추나 이 화면의 **답하기** 탭(체크박스)으로 답합니다.
- 이 저장소에는 화면 코드만 있습니다. 메일 주소는 처음 열 때 한 번 입력하면 그 기기에만 저장됩니다.
- PC(윈도우·맥)에서 같은 대화를 메신저처럼 보는 앱은 [`pc/`](pc/README.md) — 이 저장소만 있으면 돕니다.

| 탭 | 하는 일 | 보내는 메일 제목 |
|---|---|---|
| 지시 | 새 일을 맡기거나, 대화 번호(T12)를 넣어 이어서 말하기. Jira 는 `/jira PROJ-123` 줄을 넣으면 수정 허용으로 간다 | `#c 할 일` · `#cw @폴더 할 일` · `#c [T12] 이어서` · `#cw /jira PROJ-123` |
| 답하기 | 메일로 온 질문(☐ 1~4)에 체크박스로 답하기, 멈춤 | `Re: #c [T12] 답` (본문 `1,3 덧붙일 말`) |

## 웹 주소는 키로 잠겨 있습니다

GitHub Pages 는 `main` 이 아니라 **`gh-pages` 브랜치**를 보여 줍니다. 거기엔 키로 암호화한 화면만 있어서, 키를 모르면 잠금 화면만 보입니다.

- 처음 한 번 주소 끝에 `#k=키` 를 붙여 열거나 잠금 화면에 키를 넣으면, 그 기기는 키를 기억합니다(Safari 와 홈 화면 앱은 따로). 주소의 키는 열자마자 지워집니다.
- 구글 로그인에서 돌아오는 주소(`#access_token=…`)도 기억한 키로 바로 열립니다. 이미 해 둔 설정은 주소가 같아 그대로 남습니다.
- 올리기: `python pages-lock.py`(키 입력 창 → 암호화 → `gh-pages` 강제 push, 매번 커밋 하나라 옛 키 사본이 남지 않음). `--no-push` 는 만들기만.
  D&C 허브를 쓰면 `/ops` 🔑 로그인·키 「폰 페이지 키」가 키를 기억하고 단추로 올립니다(환경변수 `PAGES_LOCK_KEY` 로 넘김).
- **`index.html`·`app.js` 를 고치면 `main` push 만으로는 폰 화면이 안 바뀝니다** — 다시 올려야 합니다.
- 잠금 화면은 `lock/`(index.html · unlock.js). 암호화는 PBKDF2-SHA256 60만 번 → AES-256-GCM, 펫(`pet/`)·아이콘은 그대로 공개.
- 암호화본은 공개라 대입해 볼 수 있으니 키는 길게(10글자 이상), 폰 암호 단어와 다르게.
