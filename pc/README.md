# D&C 메신저 — PC 화면 (`pc/`)

메일로 맡긴 일을 **메신저처럼** 보는 PC 앱입니다. 쓰는 법은 [GUIDE.md](GUIDE.md)(받기·처음 설정·지시·선택지·맥). 이 폴더와 옆의 `../pet/`(폰 페이지와 같이 쓰는 인형 펫)만 있으면 돕니다 —
게이트웨이 저장소(swbins2)가 없는 PC 에서도, **윈도우·맥** 모두.

```
[윈도우]  python chat.py          또는  build.py 로 만든 DispatchChat.exe 더블클릭
[맥]      DispatchChat.command 더블클릭(처음 한 번은 우클릭 → 열기)  또는  python3 chat.py
[아이폰]  이 저장소 루트의 폰 페이지(GitHub Pages)
```

처음 열면 메일 계정을 묻고, 앱 창(Edge — 맥은 Edge 나 크롬, 없으면 기본 브라우저)으로 열립니다. 화면은 `http://127.0.0.1:8620/`.

## 메일

- **IMAP·SMTP 가 되는 메일이면 어디든** 됩니다. 메일 주소를 넣으면 잘 알려진 곳은 서버가 저절로 채워집니다.

  | 메일 | IMAP | SMTP | 비밀번호 |
  |---|---|---|---|
  | Gmail | imap.gmail.com 993 | smtp.gmail.com 587 | 앱 비밀번호(2단계 인증 필요) |
  | 네이버 | imap.naver.com 993 | smtp.naver.com 587 | 메일 설정에서 IMAP/SMTP 켜기 |
  | 다음·카카오 | imap.daum.net 993 | smtp.daum.net 465 | 메일 설정에서 IMAP 켜기 |
  | iCloud | imap.mail.me.com 993 | smtp.mail.me.com 587 | 앱 암호 |
  | 회사 메일 | 회사 안내대로 | 회사 안내대로 | 평소 비밀번호 |

  Outlook.com(개인)은 마이크로소프트가 비밀번호 로그인(IMAP 기본 인증)을 막아 지금은 안 됩니다.
- 앱은 지시를 **내 주소로 나에게** 보내고 그 메일함을 읽습니다. 실제로 일을 하는 건 게이트웨이 PC 의 메일 게이트웨이라,
  **게이트웨이가 그 메일함을 읽어야** 지시가 실행됩니다(지금: 회사 메일 · 게이트웨이 설정의 Gmail).
  회사 밖 메일은 설정의 **암호 단어**를 게이트웨이 `keyed_senders` 와 같게 넣으면 본문 마지막 줄에 `[k:단어]` 로 붙여 보냅니다(화면에는 안 보임).
- 비밀번호는 윈도우는 DPAPI(그 PC 사용자만 풀 수 있음), 맥은 키체인에 둡니다.
- 설정·로그: 윈도우 `%APPDATA%\DispatchChat\config.json` · `%LOCALAPPDATA%\DispatchChat\chat.log`,
  맥 `~/Library/Application Support/DispatchChat/`.

## 이 PC 에서 직접 실행 (게이트웨이 없이, 기본 꺼짐)

게이트웨이 PC 가 없어도 **메신저를 설치한 PC 가 직접 일하게** 할 수 있습니다. ⚙ 설정 아래 「이 PC 에서 직접 실행」 스위치를 켜면
메신저가 내 메일함에 온 지시(`#c` 읽기 · `#cw` 수정 허용 — 게이트웨이와 같은 형식)를 이 PC 의 Claude Code(`claude -p`)로 실행하고,
답을 **같은 메일함에** 넣습니다(IMAP 으로 받은편지함에 써 넣기). 답은 게이트웨이 회신과 같은 제목·머리글(`X-Dispatch-*`)·대화 번호 `[T12]`·선택지
형식이라 이 화면·폰 페이지가 그대로 보여 줍니다. 코드는 `chat_runner.py`(파이썬만 — 윈도우·맥).

- **필요한 것**: 이 PC 에 Claude Code 설치 + 한 번 로그인(터미널에서 `claude`). `claude` 를 못 찾으면 스위치 옆에 안내만 나오고 켜지지 않습니다.
- **안전**
  - 지시는 **이 계정 자신의 주소에서 온 것만** 받습니다. 설정에 **암호 단어**가 있으면 제목 끝·본문 줄 `[k:단어]` 가 맞는 것만(권장 — 내 주소를 사칭한 메일 막기).
    서버가 붙인 발신 인증(Authentication-Results)이 실패한 메일도 버립니다.
  - **스위치를 켠 시각 이후에** 메일함에 들어온 지시만. 처리한 메일은 앱 데이터 폴더의 `runner/state.json` 에 적어 두 번 실행하지 않습니다.
  - **게이트웨이 PC 에서는 켜지지 않습니다** — 게이트웨이 계정을 쓰는 중이거나 게이트웨이 인박스·저장소(`mail-gateway.py`)가 보이면 스위치가 막히고 이유가 뜹니다.
    켠 뒤에 메일함에 다른 실행기(게이트웨이)의 회신이 보이면 스스로 끄고 화면 위에 알립니다. 게이트웨이가 읽는 계정이면 켜지 마세요.
  - 수정 허용(`#cw`) 새 지시는 실행 전에 확인을 한 번 묻습니다(60분 안에 답이 없으면 취소). 읽기 지시는 읽기 도구만 씁니다.
  - 끄면 하던 일·기다리던 일도 그 자리에서 멈춥니다(회신 없음). claude 는 자식 프로세스까지 한 묶음으로 끊습니다(윈도우 작업 개체 · 맥 프로세스 그룹).
- **되는 것**: 이어서 하기(같은 대화 → `claude --resume`), 선택지 번호 답(`1,3`), 멈춤(대기 중·실행 중 모두, 지시보다 먼저 온 멈춤도), 수정 허용 확인,
  폰·메일 앱 지시에 접수 신호(ack — 폰 페이지의 '1' 이 지워짐), 진행 카드(작업 파일 + `~/.claude/projects` 세션 기록), 폰이 보낸 사진(`--add-dir`), 제한 시간 15분.
- **작업 폴더**: 기본 작업 폴더 하나(설정에서 고름) + `키=폴더` 목록(지시에 `@키`). 다른 PC 의 게이트웨이 폴더 키(@hub 등)는 여기 목록에 있어야 통합니다.
- **폰에서**: 폰 페이지·폰 메일 앱이 **같은 계정에서 자기 자신에게** 보내야 받습니다(예: 메신저 계정이 Gmail 이면 폰 페이지도 그 Gmail 로 '나에게').
- **빠진 것(게이트웨이·워커 대비)**: 전용 브라우저(Playwright MCP) · Jira 전용 도구/거부 목록(`/jira 키` 는 보통 지시로 그대로 넘김) ·
  다른 주소의 암호 단어 발신자(`keyed_senders`)·Gmail 따로 읽기·스팸함 보기·폰 주소로 회신 사본 · 작업 일시정지 깃발·알림 큐 · 회신을 SMTP 로 보내기(늘 메일함에 써 넣기).
- 상태 파일: 윈도우 `%LOCALAPPDATA%\DispatchChat\runner\`, 맥 `~/Library/Application Support/DispatchChat/runner/`. 대화 규칙은 이 폴더의 `chat-protocol.md`(exe 에 같이 묶임).

## 진행 상황(실시간)

게이트웨이 PC 에서 돌리거나 **이 PC 에서 직접 실행**을 켜면, **일하는 중인 대화**에 Claude 가 지금 무엇을 하는지(쓰는 도구·중간 말·할 일 목록)가 2초마다 카드로 올라옵니다.
워커가 만든 작업(`inbox/jobs/*.json`)과 Claude Code 가 스스로 남기는 세션 기록(`~/.claude/projects/<작업 폴더>/*.jsonl`)을 읽기만 합니다 —
게이트웨이·워커는 고칠 것이 없습니다.

- 게이트웨이 인박스: `--inbox <폴더>` → `DISPATCH_INBOX` → (윈도우) `C:\swbins2\inbox` 가 있으면 그것. 셋 다 없으면 진행 카드만 빠지고 나머지는 그대로 돕니다.
- 단계를 누르면 **자세히** — 도구에 넘긴 전체 입력(명령 전문, 고친 내용은 -/+ 줄)과 결과 출력(2,000자까지)이 그 자리에 펼쳐집니다. 펼쳐 둔 건 갱신돼도 유지됩니다.
- 다른 PC 에서는 진행 기록이 없으니 '작업 중' 표시만 보입니다.

## 회사마다 세팅

- 설정 화면(⚙)에서 메일 서버·Jira 접두어·암호 단어를 넣으면 됩니다 — 어느 회사든.
- 회사 값을 처음부터 채워 두려면 `company.example.json` 을 `company.json` 으로 복사해 채웁니다(설정 화면 기본값 + 메일 주소 프리셋).
  `build.py` 가 있으면 exe 에 같이 묶습니다. 공개 저장소에는 커밋하지 않습니다(`.gitignore`).
- **같은 코드가 두 곳에 있습니다** — 여기(swbins1/pc, 모든 회사용)와 회사 저장소 swbins2 의 `tools/dispatch-chat`(우리 회사 `company.json` 포함).
  차이는 `company.json` 뿐이어야 합니다. 한쪽을 고치면 다른 쪽에도 복사하고 `diff` 로 확인합니다:
  `diff -rq --exclude=company.json --exclude=dist --exclude=build --exclude=__pycache__ C:/swbins1/pc C:/swbins2/tools/dispatch-chat`

## 그 밖

- 화면은 127.0.0.1 에만 열리고, 보내기 같은 요청은 띄울 때마다 새로 만드는 토큰이 있어야 합니다.
- 포트가 겹치면 `DISPATCH_CHAT_PORT` 환경변수로 바꿉니다(이미 같은 포트에 메신저가 떠 있으면 새로 띄우지 않고 창만 엽니다).
- 대화 규칙(선택지·멈춤)은 게이트웨이 쪽 `chat-protocol.md`. 이 PC 에서 직접 실행할 땐 이 폴더의 사본(회사 값·브라우저 항목 없음)을 씁니다.

```
                                → 진행 상황 풀기·세션 기록 찾기 · 이 PC 에서 직접 실행(가짜 메일함·가짜 claude — 진짜 메일 서버 없이)
```
