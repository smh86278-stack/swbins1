# D&C 메신저 사용법 — 윈도우 · 맥

메일로 맡긴 일을 메신저처럼 보는 PC 앱입니다. 메일 계정만 있으면 어느 PC 에서든 같은 대화를 봅니다.
실제로 일을 하는 건 **게이트웨이 PC**(메일 게이트웨이가 도는 PC)이고, 이 앱은 그 메일함을 읽고 씁니다.
게이트웨이 PC 가 없으면 **이 PC 에서 직접 실행**(6절)을 켜서 이 PC 의 Claude Code 가 일하게 할 수도 있습니다.

---

## 1. 받기

| | 윈도우 | 맥 |
|---|---|---|
| 가장 쉬운 방법 | `DispatchChat.exe` 한 파일을 받아 아무 폴더에 둔다 | 저장소(`swbins1`)를 통째로 받아 둔다(zip 또는 `git clone`) |
| 필요한 것 | 없음 | 맥에 기본으로 있는 `python3` (처음 실행 때 "명령어 라인 도구 설치" 창이 뜨면 설치) |
| 설치 과정 | 없음 — 파일을 두는 게 전부 | 없음 |

> 맥용 앱(`DispatchChat.app`)은 맥에서만 만들 수 있습니다. 한 번 만들어 두고 싶으면 **5. 맥에서 앱으로 만들기**.

---

## 2. 처음 열기

**윈도우** — `DispatchChat.exe` 더블클릭.
**맥** — 받은 폴더의 `pc/DispatchChat.command` 더블클릭. "확인되지 않은 개발자" 라고 막히면 그 파일을 **우클릭 → 열기** 한 번. 안 열리면 터미널에서 한 번만:

```
chmod +x ~/swbins1/pc/DispatchChat.command
```

앱 창(Edge · 맥은 Edge 나 크롬, 없으면 기본 브라우저)이 열리고 **메일 계정** 창이 뜹니다.

| 칸 | 넣을 것 |
|---|---|
| 메일 주소 | 지시를 주고받을 **내 메일 주소**. 넣고 나면 Gmail·네이버·다음·iCloud 는 서버가 저절로 채워집니다 |
| 로그인 아이디 | 주소와 다를 때만(예: iCloud 는 @ 앞부분만일 수 있음) |
| 비밀번호 | Gmail·iCloud 는 **앱 비밀번호**(2단계 인증 → 앱 비밀번호 만들기). 네이버·다음은 메일 설정에서 IMAP/SMTP 켜기 |
| IMAP / SMTP 서버 | 회사 메일이면 회사 안내대로 |
| Jira 키 앞부분 | 예 `PROJ-` (Jira 탭에서 번호만 넣게) |
| 보내기 | 보통 "메일 발송". 발송이 막힌 곳이면 "메일함에 넣기" |
| 암호 단어 | **회사 밖 메일**(Gmail 등)로 지시할 때만 — 게이트웨이 담당자에게 받은 단어. 회사 메일이면 비워 둠 |

"연결 확인 후 저장" 을 누르면 실제로 메일함에 들어가 봐서 되면 저장합니다. 비밀번호는 윈도우는 DPAPI(그 PC 의 내 계정만 풀 수 있음), 맥은 키체인에 들어갑니다 — 맥에서 키체인 허용 창이 뜨면 **항상 허용**.

> 게이트웨이 PC 에서 열면 계정 창이 안 뜹니다. 게이트웨이의 계정을 그대로 쓰기 때문입니다(화면 위에 "이 PC 게이트웨이 계정").

## 3. 쓰기

### 새 지시
왼쪽 **＋ 새 지시** → 할 일을 적고 보내기(Ctrl+Enter).
- **읽기 / 수정 허용**: 읽기는 보고·조사만, 수정 허용은 파일을 고치는 일까지. 파일을 바꾸는 일이면 "수정 허용".
- **작업 폴더** 칩: 게이트웨이 PC 의 어느 폴더에서 일할지. 비우면 기본 폴더.
- 보내면 목록 맨 위에 "보냄" 으로 올라오고, 게이트웨이가 받으면 "작업 중", 답이 오면 번호(**T12** 같은)가 붙으며 "완료".

### 이어서 말하기
대화방 아래 입력칸에 적고 보내면 같은 대화(같은 세션)에 이어집니다. Claude 가 그 전 맥락을 기억합니다.

### 답할 차례(선택지)
Claude 가 물어보면 말풍선 아래 **체크박스/라디오**가 뜹니다. 고르고 "답 보내기". 덧붙일 말이 있으면 아래 칸에.

### 멈춤
돌고 있는 일을 끊으려면 **멈춤**. 하던 일은 중간에 끊기고 "멈췄습니다" 로 돌아옵니다.

### Jira
**Jira** 탭에 티켓 번호만 넣으면(`123` → `PROJ-123`) 그 건을 처리하라는 지시가 갑니다.

### 목록 정리
대화방의 🗑 은 **이 PC 목록에서만** 숨깁니다. 메일은 그대로입니다.

## 4. 진행 상황 카드 (게이트웨이 PC · 이 PC 에서 직접 실행할 때)

게이트웨이 PC 의 메신저나 **이 PC 에서 직접 실행**을 켠 메신저에서는 **작업 중인 대화방에 진행 카드**가 뜹니다 — 2초마다 갱신.

- `● Bash 작업 트리 보기` → 끝나면 `✓`, 실패하면 `✕`
- 💬 Claude 가 중간에 하는 말, `할 일 2/5 — …` 할 일 목록 진행
- 몇 단계째, 몇 초째
- **단계를 누르면** 그 도구에 넘긴 전체 입력(명령 전문, 고친 내용은 `-`/`+` 줄)과 결과 출력이 펼쳐집니다. 펼쳐 둔 건 갱신돼도 유지.

다른 PC·맥에서는 진행 기록이 없어 "작업 중" 까지만 보이고, 결과는 회신으로 받습니다.

폰(또는 메일 앱)에서 맡긴 일이 **3분 넘게** 걸리면 중간에 **진행 메일 한 통**(`진행 중 · 5분째 — 지금 하는 일 · 할 일 2/5`)이 옵니다 —
일 하나에 딱 한 번이라 메일함이 차지 않습니다. 폰 페이지·이 화면에서는 말풍선이 아니라 "작업 중" 아래 **작은 회색 줄**로 보이고, 답(완료·안 읽음)으로 세지 않으며, 최종 답이 오면 사라집니다.

## 5. 맥에서 앱으로 만들기 (선택)

`.command` 대신 더블클릭 앱을 원하면 맥에서 한 번:

```
cd ~/swbins1/pc
python3 -m pip install pyinstaller
python3 build.py
```

`pc/dist/DispatchChat.app` 이 생깁니다. 응용 프로그램 폴더로 옮겨 쓰면 됩니다(처음 한 번 우클릭 → 열기). 윈도우 exe 도 같은 방법(`python build.py`)으로 만듭니다.

회사 값(메일 서버·Jira 접두어)을 처음부터 채워 두고 싶으면 `company.example.json` 을 `company.json` 으로 복사해 채운 뒤 만드세요 — 앱에 같이 들어갑니다.

## 6. 이 PC 에서 직접 실행 (선택 — 기본 꺼짐)

게이트웨이 PC 없이 **이 PC 가 직접** 지시를 받아 일하게 합니다. 폰에서 보낸 지시도 이 PC 가 받아 처리합니다.

**필요한 것** — 이 PC 에 [Claude Code](https://docs.anthropic.com/claude-code) 설치, 터미널에서 `claude` 를 한 번 실행해 로그인. 없으면 스위치가 잠기고 안내만 나옵니다.

**켜는 법**
1. ⚙ → 아래쪽 **이 PC 에서 직접 실행**.
2. **기본 작업 폴더**(지시를 실행할 폴더)를 확인하고, 필요하면 **다른 작업 폴더**를 `키=폴더` 로 한 줄씩(지시에 `@키` 로 고름).
3. 스위치를 켭니다. 켠 **그 시각 이후에** 온 지시만 받습니다. 위쪽 상태 줄에 "· 이 PC 에서 실행" 이 붙습니다.
4. 폰에서 쓰려면 폰 페이지·폰 메일 앱이 **이 메신저와 같은 계정에서 '나에게'** 보내야 합니다.

**안전 규칙**
- **내 주소에서 온 지시만** 실행합니다. 남이 보낸 메일은 제목이 `#c` 로 시작해도 실행하지 않습니다.
- **암호 단어**(계정 칸)를 넣어 두면 그 단어가 붙은 지시만 받습니다 — 이 앱과 폰 페이지는 자동으로 붙입니다. 내 주소를 사칭한 메일을 막으려면 넣어 두세요.
- 수정 허용(`#cw`) 새 지시는 실행 전에 "실행할까요?" 를 한 번 묻습니다 — **실행**을 골라야 돌아갑니다(60분 지나면 취소).
- 한 번 처리한 메일은 다시 실행하지 않습니다. 끄면 하던 일·기다리던 일도 멈춥니다.
- **게이트웨이 PC 에서는 켤 수 없습니다**(게이트웨이 계정을 쓰거나 게이트웨이가 보이면 스위치가 잠기고 이유가 나옴).
  다른 PC 의 게이트웨이가 같은 메일함을 읽고 있으면 같은 지시가 두 번 돌 수 있으니 **켜지 마세요** — 켠 뒤 그쪽 회신이 보이면 이 PC 쪽이 스스로 꺼지고 화면 위에 알립니다.

**되는 것** — 이어서 말하기, 선택지 답, 멈춤, 수정 허용 확인, 폰 지시 접수 표시, 진행 카드(4절), 폰 사진.
**안 되는 것(게이트웨이에만 있음)** — 전용 브라우저 작업, Jira 전용 도구, 다른 주소(iCloud 등)에서 오는 지시, Gmail 따로 읽기·스팸함 보기, 폰 주소로 회신 사본.

## 7. 막혔을 때

| 증상 | 볼 것 |
|---|---|
| 위 점이 빨갛고 "메일함을 읽지 못했습니다" | 비밀번호(앱 비밀번호인지) · IMAP 이 켜져 있는지 · 회사망이면 서버 주소. ⚙ 에서 다시 저장 |
| 보냈는데 "작업 중" 이 안 됨 | 게이트웨이 PC 가 켜져 있고 그 메일함을 읽는지. 회사 밖 메일이면 **암호 단어**가 게이트웨이와 같은지, 스팸함에 안 갔는지 |
| 맥: "윈도우에서 만든 설정입니다" | 윈도우의 설정 파일을 복사해 온 경우 — ⚙ 에서 계정을 다시 넣으면 됨 |
| 창이 안 열리고 서버만 뜸 | 브라우저에서 직접 `http://127.0.0.1:8620/` |
| 8620 포트가 이미 쓰임 | 환경변수 `DISPATCH_CHAT_PORT=8621` 로 띄우기 |
| 직접 실행 스위치가 잠김 | 옆 안내대로 — Claude Code 설치·로그인, 메일 계정 먼저, 게이트웨이 PC 가 아닌지 |
| 직접 실행을 켰는데 안 돎 | 지시가 **내 주소에서** 왔는지, 암호 단어가 맞는지, 켠 **뒤에** 보냈는지. 화면 위 띠의 이유 · 로그의 `[실행]` 줄 |
| 로그 | 윈도우 `%LOCALAPPDATA%\DispatchChat\chat.log` · 맥 `~/Library/Application Support/DispatchChat/chat.log` |

설정 파일 위치 — 윈도우 `%APPDATA%\DispatchChat\config.json`, 맥 `~/Library/Application Support/DispatchChat/config.json`. 지우면 처음 상태로 돌아갑니다.
